# Laboratory work 1. Informative features of speech signals: feature extraction

Реализация лабораторной находится в `exercises_blank.py`. Скрипт `main.py`
выполняет полный эксперимент и сохраняет графики в `results/`.

Проверка конвейера без скачивания VoxCeleb:

```shell
python main.py --demo
```

Полный запуск после загрузки VoxCeleb1 test:

```shell
python main.py
```

Численные проверки:

```shell
python -m unittest test_exercises.py
```
