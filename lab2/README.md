# Лабораторная работа №2. Обучение детектора речевой активности

В `exercises_blank.py` реализован энергетический детектор речевой активности
на основе трёхкомпонентной модели гауссовых смесей. Сценарий `main.py`
вычисляет метрики для чистого сигнала, реверберации и нескольких уровней
аддитивного белого гауссовского шума.

Проверка без скачивания VoxCeleb:

```shell
python main.py --demo
```

Полный запуск после загрузки VoxCeleb1 test:

```shell
python main.py
```

Запуск численных проверок:

```shell
python -m unittest test_exercises.py
```
