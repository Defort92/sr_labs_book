# Лабораторная работа №3. Построение и сравнение дикторских моделей

В работе реализована нейросетевая модель генерации дикторских эмбеддингов:

- логарифмический мел-спектр строится непосредственно из аудиосигнала;
- ResNet извлекает локальные признаки голоса;
- статистический или внимательный статистический пулинг удаляет временную ось;
- Maxout-слой формирует эмбеддинг фиксированного размера;
- AAM-Softmax обучает модель различать дикторов;
- поддерживается онлайн-аугментация шумами MUSAN и импульсными откликами RIR.

Быстрый запуск без загрузки VoxCeleb:

```powershell
python main.py --demo
```

Полный запуск после подготовки VoxCeleb1, MUSAN и RIR:

```powershell
python main.py
```

Запуск проверок:

```powershell
python -m unittest test_exercises.py
```

Демонстрационный режим обучает две небольшие модели на синтетических голосах:
без аугментации и с аугментацией. Он предназначен для проверки кода и понимания
конвейера, а не для получения научно значимой оценки качества.
