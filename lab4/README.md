# Лабораторная работа №4. Критерии принятия решения и метрики качества

В работе исследуется система верификации диктора. Для каждой пары
«эталонная запись — тестовая запись» вычисляется оценка сходства, после чего
система выбирает одно из решений: голоса принадлежат одному человеку или
разным людям.

Реализованы:

- разделение таргет- и импостор-оценок;
- гауссовская оценка распределений и вычисление LLR;
- критерий максимума апостериорной вероятности;
- критерий Неймана–Пирсона;
- критерий Байеса;
- минимаксный критерий;
- вычисление FNR, FPR и EER.

## Как устроено выполнение

1. `ResNetSE34V2.py` превращает каждую аудиозапись в дикторский эмбеддинг —
   числовое описание особенностей голоса.
2. Для пары записей вычисляется косинусная оценка сходства. Метка `1` означает
   одного диктора, метка `0` — разных дикторов.
3. `exercises_blank.py` разделяет оценки на таргет- и импостор-наборы,
   приближает их нормальными распределениями и вычисляет LLR.
4. Критерии принятия решения выбирают порог под разные требования: минимум
   общей ошибки, ограничение FNR, заданные стоимости ошибок или неизвестную
   априорную вероятность.
5. `main.py` вычисляет показатели, строит графики и сохраняет сводку в JSON.

Все изменяемые параметры, пути и пользовательские сообщения вынесены в
`constants.py`. Короткое объяснение основных понятий находится в `theory.md`;
этот личный файл исключён из Git правилами репозитория.

Быстрый запуск на воспроизводимых синтетических оценках:

```powershell
python main.py --demo
```

Полный запуск после подготовки VoxCeleb1-O cleaned и предобученной модели:

```powershell
python main.py
```

Проверки:

```powershell
python -m unittest test_exercises.py
```

Графики и численная сводка сохраняются в директории `results`.
